# PeaceDash

Приложение для управления, мониторинга, навигации и записи треков поездок. Сделано для самокатов Ninebot F3/F3 Pro. Частично работает с G3 - протокол общий, но логика части команд отличается, поэтому не все настройки самоката на G3 доступны.

## Веб-версия

**[PeaceDash Web](https://fedulrasta.github.io/PeaceDash/)**

Дублирует функции меню «Системные» из приложения: смена региона, изменение глобального лимита скорости, глубокий сон, сброс настроек и уведомлений самоката.

Логика команд перенесена из мобильного приложения PeaceDash. Проверялась пока только на старых прошивках, работа на новых не гарантирована.

**Совместимость с браузерами.** Сайт использует Web Bluetooth, которую поддерживают не все браузеры:

- ПК — Chrome или Edge. В Firefox не заработает принципиально.
- Android - точно работает в Chrome, в остальных браузерах (Яндекс, Opera и др.) зависит от сборки. Если кнопка подключения нажимается, но ничего не происходит - проверьте, что браузеру разрешён доступ к геолокации и Bluetooth. Если пишет, что браузер не поддерживается - включите Web Bluetooth в настройках браузера или используйте Chrome.
- iOS - стандартный Safari блокирует Web Bluetooth, нужен браузер Bluefy - Web BLE Browser из App Store.

Перед подключением включите Bluetooth и GPS и закройте приложения, уже подключённые к самокату - иначе устройство не найдётся при поиске.

## Поиск устройств

Приложение ищет и показывает только самокаты Ninebot. Кнопка «Карта» (глобус) позволяет пропустить поиск и сразу перейти на главный экран в офлайн-режиме.

## Главный экран

Навигация построена на API Яндекс Карт. После тапа по карте или выбора места из списка появляется панель маршрутов с тремя видами: авто, пешком, велосипед. Для пеших и велосипедных маршрутов можно добавлять промежуточные точки, выбирать альтернативные варианты, смотреть расстояние и отменять поездку.

Для корректировки маршрута при обрыве интернета приложение в фоне подгружает офлайн-карты BRouter для своего региона. Это не полноценная офлайн-навигация, а страховка на случай пропадания сети.

Справа расположена панель инструментов карты: пробки, погода (источник данных можно поменять в настройках, часть источников в Москве работает только по Wi-Fi из-за ограничений операторов), переход к текущей геолокации, вывод навигации на дисплей самоката, дашборд и запись трека с телеметрией.

### Навигация на дисплее самоката

Источник данных - Яндекс Карты. Манёвры для авто приходят напрямую из API, для пешеходных и велосипедных маршрутов рассчитываются программно, поскольку сам API даёт манёвры только для автомобильного маршрута.

Прошивка самоката ограничивает работу шкалы прогресса на дисплее: она начинает заполняться за 100 метров до манёвра и сбрасывается со звуковым сигналом при его прохождении. На извилистых участках вместо частых сигналов на дисплей выводится общее расстояние до следующего крупного манёвра.

Чтобы данные передавались на дисплей, нужно дополнительное сопряжение по Bluetooth в официальном приложении Ninebot. Без этого шага вывод на дисплей не работает. Сопряжение из самого PeaceDash появится в одном из следующих релизов.

## Дашборд

Полноэкранная панель приборов с шестью блоками данных - в каждом можно выбрать, что отображать: ток, напряжение, пробег, температуры и другое.

## Настройки

Открываются иконкой ключа на главном экране: записи треков, настройки приложения, настройки ТС, обратная связь, о приложении.

**Настройки ТС** почти полностью повторяют функционал официального приложения. Отдельно в этом же меню — раздел «Системные» с настройками, которых нет в официальном приложении: смена региона, изменение глобального лимита скорости, активация макросов. У каждой функции раздела есть инструкция прямо в интерфейсе.

**Настройки приложения**: источник данных для погоды, средняя скорость для пешеходных и велосипедных маршрутов (используется для расчёта времени в пути), отчёт об ошибках с записью лога, сброс уведомлений на дисплее самоката.

## Треки и редактор маршрутов

В списке треков можно выделить несколько файлов галочками для массовых действий: экспорт в GPX (только геоданные, подходит для Strava, Яндекс Карт и других сервисов), отправка оригинального файла `.pdash` с геоданными и телеметрией через мессенджеры, массовое удаление.

В плеере записи, в правом верхнем углу — гаечный ключ с меню, где можно включить пропуск стоянок и отключить подсказки редактора.

Редактирование `.pdash` файла:

1. ручная корректировка - синий карандаш открывает режим, в котором можно удалять неточные точки GPS и добавлять новые;
2. переход к автоматической корректировке - зелёная стрелка;
3. выравнивание отрезков трека по дорогам средствами Яндекса — значок лупы, кнопка «назад» возвращает к ручному редактированию;
4. сохранение - зелёная дискета синхронизирует исходную телеметрию с выровненным маршрутом и сохраняет как новый файл.

## Известные ограничения

- на G3 работают не все настройки самоката;
- расшифровка серийного номера батареи и данные второй АКБ протестированы ограниченно, возможны неточности;
- для вывода навигации и уведомлений на дисплей нужно дополнительное сопряжение по Bluetooth через официальное приложение Ninebot;
- веб-версия тестировалась только на старых прошивках, работа на новых не гарантирована.
